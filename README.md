# Письма для Я и Руслана

Готовые мобильные сайты: `/for-ya/` — коробка для Я, `/ruslans/` — бар для Руслана.

## Публикация

Загрузить содержимое этой папки в корень репозитория. В Settings → Pages выбрать Deploy from a branch, ветку main и папку /(root), сохранить. Дождаться успешной публикации и проверить обе страницы.

## Письма

Текст для Я — в `for-ya/index.html`, внутри `#letter-content`; такая же страница для Я есть в корневом `index.html`.
Текст Руслану — в `ruslans/index.html`, внутри `.letter-content`. Подпись можно изменить рядом с текстом.
После изменения и публикации адреса остаются прежними, NFC-метки переписывать не нужно.

## NFC

Записать окончательный HTTPS-адрес страницы `/for-ya/` на одну метку, `/ruslans/` — на другую через NFC Tools: Write → Add a record → URL / URI → Write. Получателям нужен интернет. На iPhone звук запускается после касания страницы, если автозвук заблокирован.

## Состав

Внешний вид и сценарии перенесены без изменений. Пути к файлам адаптированы для GitHub Pages. Изображения, музыка, запись бармена и Three.js находятся в assets.
